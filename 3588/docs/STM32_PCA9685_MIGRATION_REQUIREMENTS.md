# PCA9685 功能迁移到单片机的需求说明

## 目的与结论

本文把当前工控机通过 PCA9685 控制机构的功能拆成单片机可实现的接口和指标，供固件设计、选型和联调使用。迁移后，单片机应直接产生原来 PCA9685 的 PWM/逻辑输出，并保持现有通道、电平、动作时间和停机语义；上位机继续发机构动作命令，不再通过 I²C 访问 PCA9685。

当前项目里 PCA9685 控制的是采样机构，底盘已经由 STM32 串口控制，不属于本次 PCA9685 通道迁移。升降伺服 X2P 也仍是独立 RS485/Modbus 链路，除非另行决定把它的控制器一并迁入。

## 现状依据

现行生产配置记录于 `sampling_params.py`、`mechanism_driver.py` 和 `PCA9685_COMMISSIONED.md`：设备为 I²C 地址 `0x40`，目标 PWM 频率 50 Hz；PCA9685 每通道为 12 位、4096 计数；原机构控制覆盖 CH0–10。CH0–7 使用电调式脉宽信号；CH8–10 控制夹爪 DRV8701E。初始化时 CH0–7 输出 1500 μs 并保持 3 秒。动作按设定时长自动回停，停机是持续输出 1500 μs，不是断开 PWM。

> 参数口径：代码按 50 Hz 目标值及 4096 计数换算，旧校准值 `OSCILLATOR_HZ=27,545,088` 算得 PRESCALE=133；配置记录的标称实际频率约 50.25 Hz。已验证的 1500 μs 对应计数 307（寄存器 `[0, 0, 51, 1]`）。因此首版迁移应复制现有示波器标定和计数映射，不能只按理想 50.000 Hz 重新计算后直接替换；最终以接上负载后的示波器波形和机构动作复核为准。

## MCU 必须具备的输出能力

| 项目 | 最低需求 | 说明 |
| --- | --- | --- |
| 独立输出通道 | 11 路逻辑通道：CH0–10 | CH0–7 为脉宽 PWM；CH8、CH10 为稳定高低电平；CH9 为占空比 PWM。当前 CH11–15 未使用。 |
| PWM 并发 | 至少 9 路同步工作 | 同时可能有 CH0–7 中位输出及 CH9 夹爪 EN PWM；频率目标统一为 50 Hz。最好由硬件定时器/DMA 产生，不能用阻塞延时逐路翻转。 |
| PWM 脉宽 | 可配置 1000–2300 μs，分辨率不劣于 5 μs | 与现行驱动输入钳位一致。1500 μs 为持续中位；机构动作值见下表。建议硬件定时器分辨率达到 1 μs，保证留有裕量。 |
| PWM 周期 | 20 ms 标称（50 Hz） | 保留原校准波形约 50.25 Hz 的兼容选项；按实机示波器确认决定默认值。所有脉宽应按校准映射输出。 |
| 故障恢复状态 | 上电/复位后安全初始化 | 输出初始化阶段避免不受控脉冲；CH0–7 建立 1500 μs 中位，夹爪 NS 默认低。硬件输出脚应有明确上电默认态。 |
| 通道更新 | 单通道写入不阻塞其他 PWM | 一次命令更新应在下一个 PWM 帧生效或达到等效原子更新，不能拉长其他通道周期。 |

“至少 9 路同步工作”是按当前使用形态估算的硬件并发；若固件实现时把 CH8/10 也用定时器通道驱动，则相应计入总定时器资源。更稳妥的做法是 11 路都由统一输出层管理。

这里的“全部”按当前项目实际使用的 PCA9685 功能定义：替代机构正在使用的 CH0–10 PWM/电平输出，不要求 MCU 模拟 PCA9685 的 I²C 从设备寄存器接口。PCA9685 芯片本身有 16 路；如果目标还包括保留未使用的 CH11–15，MCU 输出层应扩展为 16 路，且 16 路都能独立设定相位/脉宽或电平。当前代码和接线资料没有给 CH11–15 分配执行器。

## 通道映射与现行标定

| 通道 | 设备/用途 | 动作输出 | 停止/待机输出 |
| --- | --- | --- | --- |
| CH0 | 螺旋输送 1 | 运行 1200 μs；其他参数入口可能提供动作脉宽，需接受 1000–2300 μs 范围并限幅 | 1500 μs |
| CH1 | 螺旋输送 2 | 同 CH0 | 1500 μs |
| CH2 | 浅仓门 | 开 1200 μs；关 1800 μs | 1500 μs |
| CH3 | 中仓门 | 开 1200 μs；关 1800 μs | 1500 μs |
| CH4 | 深仓门 | 开 1200 μs；关 1800 μs | 1500 μs |
| CH5 | 旧夹爪电调保留位 | 当前仅保留旧配置/初始化中位，不驱动新夹爪 | 1500 μs |
| CH6 | 拧紧机构 | 拧紧 1300 μs；拧松 1900 μs | 1500 μs |
| CH7 | 负压风机占位 | 当前状态文档标为不再作为占位动作；不得自行假定已接线或启用 | 1500 μs |
| CH8 | DRV8701E PH 方向 | 夹紧为低，松开为高 | 保持方向电平；不承担停止功能 |
| CH9 | DRV8701E EN 速度 | 夹紧约 9.5% duty；松开约 6% duty | PWM 仍输出，由 CH10 休眠驱动器 |
| CH10 | DRV8701E nSLEEP | 运动期间高；待机/停止/急停时低 | 低 |

注：项目参数说明中 CH0/1 默认运行值是 1200 μs；通用品种参数还存在 `throttle_close=1400 μs`、兜底 1900 μs 等业务参数。MCU 应提供“设置通道脉宽”的通用命令并保留 1000–2300 μs 限幅，不要把通道动作固化成只能两档。各动作配置应由上位机或可配置表传入。

## 时序和动作行为

- PWM 基频为 50 Hz，共用周期；每个脉宽通道使用 ON=0、OFF=count 的等效波形，计数映射按现有校准复刻。
- 初始化：CH0–7 全部设为 1500 μs，连续保持 3 秒，让电调完成初始化。初始化失败时上位机不得进入可动作状态。
- 机构动作命令可包含通道、目标脉宽和持续时长。时长结束后自动回该通道 1500 μs；推荐以硬件定时器/系统 tick 调度，不以耗时 delay 阻塞串口收包和急停处理。
- 三仓联动允许 CH2、CH3、CH4 同时开始。目标仓 1200 μs 开门，其余仓 1800 μs 关门；目标仓常用 5 秒，其他仓常用 3 秒，分别到期后各自回中位。全关命令三仓同时 1800 μs，默认 3 秒后回中位。实际持续时间由命令传入。
- 夹紧：先确保 CH10=低，再设 CH8=低、CH9=9.5% PWM，之后 CH10=高；DRV8701E 唤醒等待约 1 ms，再开始计时。默认 2 秒后 CH10 拉低。
- 松开：先确保 CH10=低，再设 CH8=高、CH9=6% PWM，之后 CH10=高；等待约 1 ms 后开始计时。默认 5 秒后 CH10 拉低。
- 夹爪待机时 CH9 仍保持所设 PWM，CH10=低令驱动器休眠。急停、动作结束和正常退出均将 CH10 拉低。
- 停止、断流超时、急停应中止动作定时器，防止旧定时回调稍后覆盖新命令。

## 上位机与单片机通信接口需求

推荐在现有工控机到 STM32 的串口链路上增加“机构控制”消息类型，保留现有底盘协议类型，避免占用或改坏底盘控制语义。现有项目底盘链路默认 115200、8N1；机构协议可沿用相同 UART 参数，但需确认 MCU 串口资源及物理接口。

机构命令至少需要表达：

1. `SET_PWM(channel, pulse_us, duration_ms)`：设置脉宽，可选自动回中时长；duration=0 表示持续到后续命令。
2. `SET_LEVEL(channel, level)`：设置 CH8/CH10 的稳定高低电平。
3. `SET_DUTY(channel, duty_permille, duration_ms)`：设置 CH9 占空比；0–1000 对应 0–100%。
4. `STOP(channel)`、`STOP_ALL`、`ESTOP`、`CLEAR_ESTOP`：停止及锁定状态控制。
5. `STATUS`：回报在线、启动完成、急停锁定、故障码、PWM/逻辑通道当前目标值及动作剩余时间（若实现）。

建议协议采用帧头、版本、类型、长度、序号、负载和 CRC；校验失败、越界通道/脉宽/占空比、重复或过期动作应拒绝，并回传明确错误码。上位机需要知道“命令已接收”和“执行状态”的区别，不能把串口写成功当成机构已动作。具体帧格式尚未在当前 PCA9685 驱动文档中定义，属于固件接口设计项。

## 实时性与可靠性要求

- 急停和 STOP_ALL 优先级高于普通动作，接收后尽快将 CH0–7 回中位、CH10 拉低，并锁定新动作，直到显式清除急停。
- 串口/控制链路失联必须配置看门狗超时。建议初始取值不大于 300 ms，与现有底盘串口断流停车周期一致；但该超时会影响持续动作，应由机构控制上位机按动作心跳方案确认后再定。超时后的默认安全动作：CH0–7 回 1500 μs，CH10 低。
- 单次 I²C 写失败在旧驱动中最多尝试 3 次、间隔 10 ms；迁移后输出由 MCU 本地定时器承担，串口参数设置失败要返回错误，不得静默接受。
- MCU 看门狗复位、通信校验失败和电源欠压后，输出必须进入已定义安全态；软件 PWM 中断不能阻塞串口、急停或看门狗服务。
- 1500 μs 是当前系统定义的停止/中位命令，不等于断电或硬件急停。软件急停不能取代电机动力电源的物理急停。

## MCU 资源选型检查

固件/硬件选型时逐项确认：

- 是否有足够的硬件 PWM 定时器通道；若不足，可用单个高分辨率定时器加 DMA/输出比较实现多路边沿调度。
- 定时器时钟是否可整除出 1 μs 或更细时间基准，并能稳定产生 20 ms 周期。
- UART 是否可与底盘控制复用而不改变底盘协议、收发时序和现有引脚；否则需要第二路 UART/CAN 等明确链路。
- 输出电平是否兼容现有电调/DRV8701E 输入（确认 3.3V 是否为高电平有效，确认共地及是否需要缓冲/隔离）；PCA9685 输出驱动模式和实际电压应现场测量后复刻。
- 上电复位期间各输出的默认电平、外部上拉/下拉、OE/使能脚和动力急停如何实现。
- 多路 PWM 同时切换时 MCU 负载、ISR 执行时间、串口收包和急停延迟是否满足现场要求。

不能仅凭 MCU 的主频判断适配。关键条件是定时器输出能力、电平接口、复位安全状态和并发通信能力。

## 迁移验收表

| 验收项 | 通过标准 |
| --- | --- |
| 频率与脉宽 | CH0–7 实测周期约 20 ms；1500、1200、1800、1300、1900 μs 指令与现有波形/机构动作一致，按旧校准值复刻并记录误差。 |
| 多路同时输出 | CH2–4 同时动作时，各通道周期与脉宽不明显漂移，CH0/1 等中位输出不中断。 |
| 夹爪时序 | CH8 方向正确；CH9 分别约 9.5%/6%；CH10 先低再高，约 1 ms 后驱动；结束和急停时 CH10 低。 |
| 自动回停 | 命令时长到期后指定通道回到持续 1500 μs，其他通道动作不被误停。 |
| 急停/故障 | 急停能打断所有动作并锁定；串口拔除、CRC 错误、MCU 复位后均进入已约定安全态。 |
| 上电行为 | 复位及启动过程中不出现意外全速/误动作脉冲；CH0–7 建立中位并保持 3 秒。 |
| 实机联调 | 空载波形验收后再接执行器，逐个方向、限位、温升和持续时间验证；保持物理急停可触及。 |

## 明确不属于本次迁移的部分

- 底盘左右履带控制、遥控接收、导航闭环和现有 STM32 底盘协议；该链路已经由 STM32 处理。
- X2P 升降伺服的 RS485/Modbus 位置控制，除非单独把升降伺服控制也并入目标 MCU。
- 业务流程决策（采样状态机、粮种参数、流程阶段和 UI）。初期建议由上位机继续管理，MCU 只负责可靠执行通道命令、动作定时和安全停机。
- 当前没有确认接线或仍属占位的 CH7 风机动作。启用前应完成现场接线和标定。
