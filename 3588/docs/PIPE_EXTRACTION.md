# 正式流程：夹紧去重与逐节取管

加管仍执行“拧紧 → 松夹 → 夹紧”。夹紧动作成功且等待结束后，工作流记录夹紧状态，下压阶段直接进入往复下压，不再重复夹紧。首次插管仍先夹紧；下压后的松夹、伺服回位和再次夹紧仍保留。松夹动作完成并等待结束后，记录已松开状态；确认取出该节后，下一轮直接下降到 20 cm，不重复松夹。动作进行中、换点位、任务重置或停止时，夹具状态记为未知，不能据此跳过必要动作。

插管时，每轮下压都会使上一轮松夹记录失效。机构守护进程在执行 `return` 回零前检查本轮松夹指令、PCA9685 松夹定时器和单片机松夹时长（当前 4 秒；本机默认 5 秒取较长值）。缺少本轮松夹动作、松夹未结束或急停时禁止上升；等待结束会记录 `UNCLAMP_COMPLETE_BEFORE_RETURN`。此检查依据指令及计时，没有机械到位反馈。

## 点位取样完成后的动作

同一位置的深度取样之间继续使用现有加管、下压流程。当前点位最后一个深度完成吸粮、输粮、关仓并点击“确认”后，才开始逐节取管；最后一个点位同样必须完成取管才能确认返航。

每节按以下顺序处理，管节从最后插入的一节开始取出：

1. 检查升降编码器通信。
2. 夹具尚未确认松开时先松开；上一节取出前已完成松夹时，直接下降到 20 cm。
3. 夹紧；伺服直接上升到本轮保存的 0 位，不做往复运动。
4. 保持夹紧，显示“请托住取样管”和当前剩余管节数。
5. 人工托住待拆管节，点击“已托住管子，开始松管”。
6. 拧松续接接头，然后松夹。最后的首节管没有自动续接动作，因此跳过拧松。
7. 显示“请取出当前管节”。人工取出该节并离开运动机构，点击“已取出管子”。
8. 此时才将剩余管节数减一；有剩余则继续下一节，全部取出才导航到下一点或提示返航。

## 升降与失败处理

本次沿用现有正式流程的管节计数和 `PRESS_SEGMENT_CM` 单次行程（当前为 20 cm）。`extract_prepare` 在松夹时将实际上方编码器位置保存为本轮 0 位，直接下降到 20 cm；`extract` 在夹紧后直接返回保存的 0 位。下降和上升各只有一个目标位置，不使用插管的往复参数。两者必须使用相同距离，不能在未完成下压回程时启动取管，也不能把取管原点当成下压回程原点。

夹紧、松夹、拧松沿用品种动作时长及 0.5 秒停稳余量。升降指令不自动重试；取管失败或急停保留未完成的原点并停止流程，禁止跳过取管继续导航。发生未完成升降后，需要按已有机械复位流程处理，不能重放旧动作。人工确认取出前，管节计数保持不变。

软件测试不连接硬件；实际夹持、接头脱开、20 cm 行程与可取管位置仍需现场联调验证。现有 STM32 协议没有反向拧管命令，拧松继续走 PCA9685 CH6，MCU 只收到停止拧紧指令。
