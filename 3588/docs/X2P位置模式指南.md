# X2P系列经济款脉冲型伺服驱动器 - 位置控制与自动调整模式指南

本文档汇总了X2P系列伺服驱动器在“位置控制模式”及“增益自动调整模式”下的核心工作逻辑、参数配置（Pn系列功能码）及调试步骤。

---

## 1. 位置控制模式基础设置

位置控制模式是通过外部输入的脉冲数量来确定位移量，通过脉冲频率来确定旋转速度。

### 1.1 核心模式激活
* **Pn001 (控制模式)** 
  * **设定值**: `0` (位置控制模式)
  * **生效时间**: 重新上电生效

### 1.2 位置指令来源与形态选择
* **Pn321 (位置指令源选择)**
  * `0`: 外部脉冲指令（位置指令来源于外部脉冲，最常用）。
  * `1`: 内部多段位置指令（来源于 Pn700~Pn769）。
* **Pn006 (位置指令脉冲方向取反)**
  * `0`: 正常。
  * `1`: 位置指令脉冲方向取反。
* **Pn007 (外部脉冲指令输入形式)**
  * 脉冲指令共有三种主要形态（结合 Pn006 和 Pn007 使用）：
  * `Pn007 = 3`: 脉冲序列 + 符号 (PULSE + SIGN)。
  * `Pn007 = 0/2`: 90° 两相正交脉冲 (A相 + B相，4倍频)。
  * `Pn007 = 1`: 双脉冲序列 (CW正方向脉冲 + CCW负方向脉冲)。
* **输入频率限制**:
  * 差分接口最高频率：`500 Kpps`
  * 集电极开路接口最高频率：`200 Kpps`

### 1.3 电子齿轮比设置 (Electronic Gear Ratio)
电子齿轮比用于匹配上位机发送的指令脉冲与电机实际旋转的物理脉冲之间的关系。

* **Pn008 (电机旋转1圈的指令脉冲数)**
  * 若设为非0值（1~8388608），则直接以此值作为电机转一圈所需的脉冲数，忽略 Pn010/Pn012。
  * 若设为 `0`，则启用 Pn010 和 Pn012 的分子分母设定。
* **Pn010 (电子齿轮比分子1)**
  * 设定范围: 0~1073741824。设为0时系统默认为编码器分辨率。
* **Pn012 (电子齿轮比分母)**
  * 设定范围: 1~1073741824。
  * **计算公式**: 实际位置 = 指令脉冲输入 × (Pn010 / Pn012)
* **动态切换**:
  通过配置外部数字输入信号，可动态切换电子齿轮比分子 (Pn010, Pn014, Pn016, Pn018)。

### 1.4 位置指令滤波与平滑
用于处理上位机脉冲未加减速、频率过低或齿轮比过大导致的运行不平稳。

* **Pn223 (位置 FIR 滤波器)**
  * **单位**: ms | **范围**: 0.0 ~ 512.0
  * 用于抑制减速停止瞬间发生的振动。根据测定的振动周期输入相应的 ms 值。
* **Pn322 (外部脉冲指令平滑滤波时间)**
  * 使输入脉冲指令平滑，但会产生指令延迟。适用于上位机无加减速功能或运行时阶跃步进的情况。
* **Pn323 (外部脉冲输入高频滤波时间)**
  * 用于消除高频干扰防丢步。需满足条件：`滤波时间 Tf ≤ (20%~25%) 输入信号最小宽度 Tmin`。

## 2. 自动调整模式与增益调谐 (Auto-Tuning)

驱动器内置实时自动调整功能，可推断机械特性（负载惯量比），并自动设定最优的位置环、速度环等增益参数。

### 2.1 增益调整模式选择 (Pn002)
* **Pn002 = 0 (手动模式)**:
  * 参数自调整无效，需全手动调整增益。
* **Pn002 = 1 (自动调整模式 1)**:
  * **适用场景**: 负载惯量比基本恒定或系统无法准确推断惯量时。
  * **操作机制**: 停止实时惯量推断。用户必须手动输入 **Pn004 (负载惯量比)** 和 **Pn003 (刚性)**。系统根据这两项自动计算并修改 `Pn100`、`Pn101`、`Pn102`、`Pn128`。
* **Pn002 = 2 (自动调整模式 2 - 出厂默认)**:
  * **适用场景**: 负载惯量比经常变化的场合。
  * **操作机制**: 伺服自动在线实时辨识负载惯量比并写入 Pn004（每30分钟存储一次）。用户只需设定 **Pn003 (刚性)**。系统自动修改 `Pn100`、`Pn101`、`Pn102`、`Pn128`。

### 2.2 自动调整模式 2 的限制条件
在以下情况下，模式2可能无法正常推断惯量，建议改用模式1或手动模式：
1. 加减速时间常数过长（零速加速到2000r/min时 > 5s）。
2. 电机转速过低（< 150r/min）。
3. 负载惯量比过大（> 100倍）。
4. 加减速转矩过小（< 额定转矩的10%）。
5. 负载变化极其剧烈或机械结构存在严重松动/反向间隙。

### 2.3 刚性等级与增益参数的关联 (Pn003)
**Pn003 (刚性等级)** 范围为 1~31。刚性值越大，系统响应越快，定位时间越短，但过大易引起机械振动。

在自动调整模式下，Pn003 的调整会直接联动系统自动重写以下 4 个核心底层增益参数：
1. **Pn100 (位置控制增益, rad/s)**：决定位置环响应性。值越大，位置跟随误差越小。
2. **Pn101 (速度控制增益, Hz)**：决定速度环响应性。为了提高位置响应，必须提高速度增益（速度环响应频率需为位置环的 4~6 倍）。
3. **Pn102 (速度环积分时间常数, ms)**：消除稳态误差。值越小响应越快，过小会振动。
4. **Pn128 (转矩给定滤波时间常数, ms)**：对速度环输出转矩进行低通滤波，消除高频共振。

*刚性等级参考场景*:
* `Pn003 = 8~11` (速度环带宽 9~18Hz): 大型传送带。
* `Pn003 = 12~14` (速度环带宽 22~35Hz): 机械手。
* `Pn003 = 15~18` (速度环带宽 40~75Hz): 普通搬运机。
* `Pn003 = 19~20` (速度环带宽 90~115Hz): 高精度机床。
* `Pn003 = 21~23` (速度环带宽 140~210Hz): 注塑机、堆垛机。

### 2.4 辅助功能与调试 (Fn 参数)
* **Fn008 (离线惯量辨识)**
  * 在刚性调谐前，可使用此功能自动测算系统负载惯量比，结果将自动填入 Pn004。
* **Fn001 (JOG 点动功能)**
  * 脱开上位机独立测试电机旋转及机械结构。

## 3. 典型调试步骤流程

1. **基础通电与确认**: 设置 `Pn001=0`，配置 `Pn006`、`Pn007` 及电子齿轮比，确认脉冲接收正常。
2. **初始自整定评估**:
   * 默认使用 `Pn002=2` (自动模式2) 运行设备。
   * 观察运行表现。若出现无法收敛或剧烈震荡，说明自动推断条件不满足。
3. **切换自动模式1**:
   * 若模式2失败，设 `Pn002=1`。
   * 使用 `Fn008` 离线辨识惯量，或根据经验手动设置 `Pn004` (负载惯量比)。
4. **调节刚性**:
   * 逐渐增加 `Pn003` (例如从 10 慢慢加到 15、20)。
   * 每增加一次刚性，观察设备运行是否平稳。若出现尖锐异响或高频震荡，退回上一级刚性或启用陷波滤波器 (Pn200系列) 抑制机械共振。
5. **微调 (如需进入手动模式 `Pn002=0`)**:
   * 优先加大 `Pn101` (速度增益)。
   * 其次减小 `Pn102` (速度积分常数)。
   * 然后加大 `Pn100` (位置增益)。
