# 页面设计需求

## 通用约束

- 屏幕：7 寸触摸屏，1920×1080 @ 96DPI
- 配色/字体：见 `DESIGN.md`
- 框架：PySide2/Qt5，输出 QSS + 布局描述（非 HTML）
- 深色底色 `#0D1117`，全局无外边框

---

## Page 1 — 主页面 (Main Dashboard)

### 布局

```
┌──────────────────────────────────────────┐
│  Status Bar (top): 连接状态 · 小车速度   │
├────────┬─────────────────────────────────┤
│        │                                 │
│ Left   │   Center:                       │
│ Panel  │   - 点云地图预览 / Logo         │
│        │   - 当前位姿 (x, y, z)         │
│ 4 nav  │                                 │
│ btns   │                                 │
│        │                                 │
│ +急停  │                                 │
│        │                                 │
├────────┴─────────────────────────────────┤
│  Alarm Bar (bottom): 滚动告警信息        │
└──────────────────────────────────────────┘
```

### 需求
- 左侧面板：4 个导航按钮（开始采样 / 地图预览 / 建图管理 / 系统设置），竖排 + 急停按钮
- 中央区域：大块，优先显示点云地图或默认状态
- 顶部状态栏：网络连接、ROS 状态、小车速度
- 底部告警栏：滚动显示警告/错误信息
- 紧凑布局，左侧面板不宽于 120px

## Page 2 — 任务列表 (Task List)

### 布局

```
┌──────────────────────────────────────────┐
│  Filter Tabs: [云端任务] [本地调试]       │
├──────────────────────────────────────────┤
│  [获取云端任务]                    [承接] │ ← 云端 Tab
├──────────────────────────────────────────┤
│  ┌────────────────────────────────────┐  │
│  │ ✓  RW2026070908  廒间: 3          │  │
│  │    检测: 生化(1), 理化(2)          │  │
│  │    点位: (4, 4)  深度: [4, 5, 7]  │  │
│  └────────────────────────────────────┘  │
│  ┌────────────────────────────────────┐  │
│  │   RW2026070901  廒间: 12          │  │
│  │    检测: 生化(1), 理化(2)          │  │
│  └────────────────────────────────────┘  │
├──────────────────────────────────────────┤
│                    [本地创建工单]         │ ← 本地 Tab
└──────────────────────────────────────────┘
```

### 需求
- 顶部筛选标签切换云端/本地任务
- 云端：获取按钮 + 任务卡片列表 + 承接按钮（右对齐）
- 本地：任务卡片 + 创建按钮（右对齐）
- 任务卡片紧凑：单行 ID + 廒间，第二行检测类型（生化/理化 + 数字ID），第三行点位/深度
- 承接按钮 disabled 时文字必须可读（浅灰 `#8B949E` 起）
- 创建工单按钮文字不被遮挡

## Page 3 — 引导页 / 任务执行 (Guidance)

### 布局

```
┌──────────────────────────────────────────┐
│                                          │
│         【当前步骤：正式采样中】           │ ← 步骤标题 (large)
│         ⏸ 已暂停                         │ ← 状态提示
│                                          │
│    当前深度约 2m，第 2 节管...             │ ← 详情说明
│                                          │
│         ████████████░░░░  66%            │ ← 进度条
│                                          │
│  ┌──────┐  ┌──────┐  ┌──────┐           │
│  │ 暂停  │  │ 继续  │  │ 急停  │           │ ← 安全按钮 (正式采样时)
│  └──────┘  └──────┘  └──────┘           │
│                                          │
│           ┌──────────────┐               │
│           │   结束任务    │               │ ← 结束按钮 (全流程可见)
│           └──────────────┘               │
│                                          │
│           (二次确认弹窗)                  │
└──────────────────────────────────────────┘
```

### 需求
- 步骤标题大而醒目
- 详情文字说明当前操作
- 进度条显示完成度
- 安全按钮行：暂停/继续/急停（仅正式采样态显示）
- **结束任务按钮**：独立一行，从任务开始到结束全程可见
- 点击结束任务 → 弹出确认对话框（"确认结束当前任务？"）
- 按钮 disabled 态文字必须可读
- 整体居中布局，按钮间距 8-12px
