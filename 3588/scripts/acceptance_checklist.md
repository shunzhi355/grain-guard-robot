| 5.3 | 切面上传 | 切面数据经 HTTP 上传云端，云端可查看 | ⏳ 待补齐 | ⚠️ 待云API. 代码就绪: uploader.py. Windows验证: python mock_cloud_server.py; curl -X POST localhost:8889/api/maps -d '{"points":[...],"height":0.5}' | 依赖云API地址 |

**上传数据格式说明（2026-07-23更新）：**
- 上传数据格式：JSON，包含外轮廓坐标点列表 + 切面高度
- `type` 字段区分 contour / full：
  - `"type": "contour"` — 外轮廓边界点（默认），由 PointCloudSlicer.extract_contour() 自动提取
  - `"type": "full"` — 全量切面点（contour_only=False 时）
- `points` 为 `[{"x": float, "y": float}, ...]` 格式，contour 模式下通常几十个点
- 字段示例：
  ```json
  {
    "type": "contour",
    "height": 0.5,
    "aojian_id": "WH-A01",
    "points": [{"x": 1.1, "y": 2.3}, {"x": 1.2, "y": 2.4}],
    "mac": "AA:BB:CC:DD:EE:FF"
  }
  ```
