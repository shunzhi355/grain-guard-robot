# 本机 PCA9685 已验证配置

2026-09-27：模块逻辑电源断电时 I2C2 的 0x40 消失，上电后恢复。
用户随后确认 CH0–7 均有正常输出波形。手册 TP 标注 I2C4 不作为本机
总线映射依据，禁止因该标注自动切换总线。

正式入口：`scripts/start_industrial_pc.sh` → `grain_sampling_workflow.mechanism_node`
→ `grain_sampling_devices.mechanism_driver.PCA9685`。独立测试也使用同一驱动。

| 配置 | 本机验证值 |
| --- | --- |
| 设备 / 地址 | `/dev/i2c-2` / `0x40` |
| 控制器身份 | DT alias `i2c2`，`feaa0000.i2c` |
| 时钟换算 | `sampling_params.PCA9685_OSCILLATOR_HZ = 25000000` |
| 目标频率 / PRE_SCALE | 50 Hz / 121 (`0x79`) |
| 工作模式 | MODE1 `0x21`（RESTART 瞬时位除外），MODE2 `0x04` |
| 1500 μs 计数 | 307，通道寄存器 `[0, 0, 51, 1]` |

正式启动对 CH0–7 发送 1500 μs 中位，保持 3 秒初始化电调。
随后按原有动作脉宽、时长控制；不是始终固定 1500 μs。
CH7 风机不再作为占位动作。待机、动作结束、停止、急停及正常退出后，
CH0–7 均持续输出1500μs中位，不再使用 FULL_OFF。急停锁定和伺服停止保留。
时钟频率是计算参数，精确周期/脉宽仍以示波器测量为准。

每次通道写入均回读；异常上抛给原有三次重试逻辑，脉宽写失败先尽力回中位。
初始化失败会尝试将所有配置通道回中位并终止机构节点启动。
通信失效时不能保证中位写入成功；紧急情况仍需硬件急停/动力断电。
旧接口 `channel_off/all_off` 保留兼容名称，但同样执行回中位，不再切断信号。
不使用 I2C 广播复位，不触碰未配置通道，也不恢复已移除的 CH9/10 控制。
启动前必须停止独立测试，避免多个进程争用芯片。关闭文件描述符不会关闭芯片PWM。
